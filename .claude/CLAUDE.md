## Comandos que Já Aprendi

### Terminal (PowerShell — Windows)

| Comando              | O que faz                          |
|----------------------|------------------------------------|
| `ls`                 | Lista arquivos e pastas            |
| `cd nome-da-pasta`   | Entra em uma pasta                 |
| `cd ..`              | Volta uma pasta                    |
| `mkdir nome`         | Cria uma pasta nova                |
| `type nome-do-arquivo` | Mostra o conteúdo de um arquivo  |

### Slash Commands (Claude Code)

| Comando       | O que faz                                      |
|---------------|------------------------------------------------|
| `/help`       | Mostra ajuda geral do Claude Code              |
| `/clear`      | Limpa o histórico da conversa atual            |
| `/config`     | Abre configurações (tema, modelo, etc.)        |
